## Precision in our tools. Purpose in our software.

LEUCO supplies precision tooling for machining wood, plastics, and composites. Here, we bring that practical focus to software: solving everyday problems, improving how we work, and keeping useful knowledge within reach.

This organization is home to LEUCO US's software projects, automation, and shared development resources.

### What we build

| Area | Purpose |
| :--- | :--- |
| **Applications** | Tools that help people complete real business tasks. |
| **Automation** | Workflows that reduce repetitive steps and make processes more consistent. |
| **Shared knowledge** | Documentation and decisions that help the next person understand the work. |
| **AI-assisted development** | Reusable guidance and tooling for building with Claude and reviewing the results. |

### Work together. Keep the history.

You do not need to be a software engineer to contribute. Start with a problem you understand, make a focused change, and check that the result works.

We use branches and pull requests to discuss proposed changes before they become part of the main project. That keeps the work reviewable and preserves the reasoning behind it.

**[Read the contribution guide →](https://github.com/Leuco-Tool-US/.github/blob/main/CONTRIBUTING.md)**

### For team members

Sign in with the GitHub account connected to LEUCO US, then open **[Repositories](https://github.com/Leuco-Tool-US?tab=repositories)** to see the projects available to you. For a specific project, start with its README.

Missing access? Contact your organization administrator through the company's internal support channel.
