# LEUCO US on GitHub

We use GitHub to collaborate on software projects. A repository holds a project's files, documentation, and change history. A pull request lets teammates discuss and review a proposed change before it becomes part of the project.

GitHub also offers issue tracking, project boards, and automated checks. Teams can adopt these tools as needed. You can start by browsing a repository or reviewing a proposal in your browser. When you submit a change, follow the checks and review requirements for that repository.

## Explore the repositories

Sign in with your work GitHub account and browse the organization's repositories. Open a project's README to learn what it does and how to contribute. Ask your organization administrator if you need access to a private repository. [Browse repositories](https://github.com/orgs/Leuco-Tool-US/repositories)

## Work in Visual Studio Code

Download Visual Studio Code if you plan to edit project files or work on an application. VS Code supports Git and GitHub sign-in. Install Git for local source control, the GitHub Pull Requests extension to work with pull requests and issues, and the Claude Code extension to use Claude in the same window. [Download VS Code](https://code.visualstudio.com/download) · [GitHub in VS Code](https://code.visualstudio.com/docs/sourcecontrol/github) · [Claude Code in VS Code](https://code.claude.com/docs/en/vs-code)

## Use Claude to help with GitHub

The company's **Leuco Workflows** plugin adds skills for finding the right repository, explaining pull requests, preparing changes for review, and helping fix naming check failures. Enable the plugin in your company Claude account, give your Claude Code session access to the repository, and describe what you want in ordinary language.

For a first task, give Claude a pull request link and ask it to explain what changed, why it matters, and what you should review. You can read the explanation and draft feedback in chat without opening source files. If Claude prepares a change, ask it to explain what it changed and how it checked the result before you approve or publish it.

See the [getting started guide](https://github.com/Leuco-Tool-US/.github/blob/main/docs/START-HERE.md) for browser and editor walkthroughs, and the [contribution guidelines](https://github.com/Leuco-Tool-US/.github/blob/main/CONTRIBUTING.md) before submitting changes.
