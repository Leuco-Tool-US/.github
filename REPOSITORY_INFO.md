# Repository Setup

Required repository name: `.github`

Suggested GitHub description:

> Organization-wide GitHub defaults, issue and pull-request templates, and reusable workflow templates for LEUCO repositories.

Recommended visibility for a normal GitHub organization: Public

Important: GitHub requires the organization `.github` repository to be public for default community health files to apply to other repositories, unless the organization is using Enterprise Managed Users with different rules.

Because of that requirement, keep every file in this repository safe for public viewing. Do not add secrets or proprietary company information.

Do not add an open-source license unless the company intentionally decides to license content from this repository.
